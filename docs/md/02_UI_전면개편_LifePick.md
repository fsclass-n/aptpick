# 02. UI 전면 개편 — "Living Editorial" 디자인 & Life Pick (2026-11-26)

## 목표
- 상용 라이프스타일 커머스(W컨셉·29CM) 수준의 에디토리얼 UI를 부동산 맞춤 추천 플랫폼에 적용
- 기존 경쟁 서비스(가격·상승률 중심)와 다른 차별점으로 **라이프스타일 기반 추천(Life Pick)** 부각
- 실사 이미지(Unsplash)로 비주얼 강화, 단 **실제 단지 사진이 아님**을 명확히 표시

## 디자인 시스템 (`frontend/src/styles/index.css`)
| 항목 | 내용 |
|---|---|
| 팔레트 | 웜 아이보리 바탕(`ivory`·`sand`·`line`), 잉크 차콜(기존 `navy-*` 토큰명 유지), 클레이 포인트(`brand-*`), 세이지 보조(`mint-*`) |
| slate 재정의 | `slate-*` 를 웜 그레이로 재정의해 기존 전 화면 톤을 일괄 전환 |
| 타이포 | `display`(56px) 유틸 추가, H1 34 · H2 26 · H3 20, eyebrow 자간 0.18em 대문자 |
| 컴포넌트 | 버튼 pill(rounded-full), 잉크 Primary / 클레이 Accent(`btn-accent`), 이미지 스크림(`scrim`), 밑줄 호버(`link-line`), 켄번스 애니메이션 |
| 의미 색상 | 상승 레드 · 하락 블루 · 보합 그레이 유지, 주의 색상은 클레이와 구분되는 앰버로 조정 |
| 차트·지도 | Recharts 시리즈 색상, 지도 가격대 마커 색상을 새 팔레트로 통일 |

## 공통 레이아웃
- **UtilityBar**(데스크톱 상단, sticky 바깥) — 서비스 소개 · 데이터 출처 · *테스트 관리자 체험* 바로가기
- **Header** — 72px, 아이보리 블러 배경, 밑줄 활성 표시, 검색 아이콘, **Life Pick 메가 메뉴**(페르소나 6종 이미지 타일), 모바일 드로어에 Life Pick 바로가기
- **Footer** — 브랜드 메시지 · 서비스 · Life Pick · 정책(개인정보처리방침 강조) · 고객센터(운영시간·이메일·문의/제휴 모달) · SNS 아이콘 · 면책 고지 · Unsplash 출처
  - SNS 주소는 `utils/config.js` `LINKS.instagram/youtube/blog` — 빈 값이면 '준비 중' 비활성 표시 (GitHub 만 실제 링크)
- **ToTop** — 우측 하단 원형 버튼 + 스크롤 진행률 링
- **PageHeader** — `image` 지정 시 사진 밴드(검색·시장·추천·리포트·예측·관심 매물·소개), 미지정 시 아이보리 에디토리얼 헤더

## 메인 페이지 (`pages/Home.jsx`)
1. 풀블리드 히어로(서울 야경) + 통합 검색 + 인기 지역 + 글래스 KPI 스트립 + 데이터 기준일/샘플 배지
2. **Life Pick** — "어떤 하루를 살고 싶나요?" 페르소나 6종 카드(3:4)
3. AI Pick — 이미지 중심 카드 + 추천 점수 배지 + 라이프 태그
4. Neighborhood Lookbook — 지역 평당가·전년 대비 모자이크
5. Why aptpick — "가격 순위가 아니라, 생활 적합도 순위" 3단계 설명 + 도구 바로가기
6. Market Snapshot(지역 평당가 순위 · 최근 실거래) · AI 리포트 · CTA(관심 단지 알림 / 테스트 계정)

## 차별화: Life Pick (`utils/lifestyle.js`)
- 페르소나 6종: 신혼부부 · 아이 키우는 가족 · 1인 직장인 · 반려동물과 함께 · 여유로운 시니어 · 가치 투자자
- 각 페르소나는 기존 추천 API(`/api/ai/recommend`) 입력 조건 프리셋(목적·거래유형·예산·면적·방 수·교통/학군/인프라 가중치)
  → **추천 엔진·가중치 규칙은 변경하지 않음** (backend `recommendation.py` ↔ `mock/recommend.js` 동기 규칙 영향 없음)
- `/recommend?persona=<id>` 진입 시 프리셋 적용 후 즉시 추천, 상단 페르소나 스트립으로 전환·해제, 조건은 자유롭게 수정 가능
- **라이프 태그**(#역세권 #학세권 #슬세권 #가성비 #시세 안정 #거래 활발): 추천 구성 점수 80점 이상일 때만 표시 (근거 없는 태그 금지)

## 이미지 정책 (`utils/images.js`)
- Unsplash 이미지 ID 34개를 응답(200)과 내용(컨택트 시트)으로 확인 후 용도별 매칭
- 단지 이미지는 단지 id 로 12장 풀에서 고정 매칭, 카드·상세·관심 매물에 **'참고 이미지'** 라벨, 상세는 '실제 단지 사진 아님' 명시
- 이미지 로드 실패 시 기존 SVG 단지 일러스트로 자동 대체 (`AptVisual`)

## 유지된 사항
- 최초 진입 `/` 메인, 모든 페이지 공통 MainLayout(헤더·푸터)
- 실제 관리자(`ADMIN_SECRET_KEY` 보안 키 로그인, CRUD) / 테스트 관리자(메뉴·뷰 노출, 쓰기 차단 — 백엔드 미들웨어 최종 방어) 권한 체계 변경 없음
- 샘플 데이터 배지, 호가/실거래 구분, AI 결과 기준일·한계 표시
