# AI 모델 설계서 및 성능 평가서

> 작성: 김모란 (AI) · 평가 데이터: **aptpick 가상 샘플 데이터** (2023-11 ~ 2026-10, 매매 3,966건) — 실제 시장 성능이 아닙니다.
> 실데이터(국토교통부) 수집 후 `python -m ai.price_prediction.train` 등으로 재평가해 이 문서를 갱신해야 합니다.
> 재현: 결과 원본 `ai/evaluation/results/*.json`

## 1. 아파트 적정가격 추정 모델 (`backend/app/services/prediction.py`)

| 항목 | 설계 |
|---|---|
| 타깃 | log(㎡당 거래가) → 예측 후 × 전용면적 |
| 피처 (15) | 전용면적, 층, 경과연수, log 세대수, 위·경도, 지하철·학교 거리, 버스·마트·병원·공원 수, **지역 시세지수**(직전 3개월 평균, 현재 월 제외 → 누수 방지), **단지 프리미엄**(지역지수 대비 잔차 평활 타깃 인코딩, m=8), 시점 |
| 전처리 | 해제 거래 제외, 직거래(특수관계 가능성) 학습 제외, 결측은 HGB 기본 처리 |
| 알고리즘 | HistGradientBoostingRegressor (max_iter 220, lr 0.08, leaf 31, min_leaf 20, L2 0.1) |
| 예측 구간 | 분위수 회귀(0.1·0.9) + holdout 기반 분할 등각 배율 보정(목표 80%) |
| 검증 | 시간 기준 holdout: 최근 3개월(2026-08~10, 333건) / 학습 3,590건 → 평가 후 전체 데이터 재학습 |
| 단기 전망 | 지역 최근 6개월 log 시세 기울기 × 3개월 (참고용, 구간 확장) |
| 설명 | 순열 중요도, 층·경과연수 민감도 곡선 |

### 1.1 모델 비교 (동일 피처·분할, `ai/price_prediction/train.py`)

| 모델 | MAE(만원) | RMSE(만원) | MAPE | R² |
|---|---|---|---|---|
| **HistGradientBoosting (운영)** | **4,263.7** | **7,545.0** | **3.26%** | 0.993 |
| RandomForest | 4,738.6 | 8,174.5 | 3.53% | 0.9917 |
| Ridge | 4,885.7 | 8,094.8 | 3.87% | 0.9919 |
| 기준선 (지역지수 + 단지 프리미엄) | 5,125.4 | 8,009.1 | 4.44% | 0.9921 |

- XGBoost·LightGBM·Optuna·SHAP 은 `ai/requirements.txt` 설치 시 같은 스크립트에서 자동 비교(`--optuna N`, `--shap`) — 이번 평가 환경에서는 미설치로 실행하지 않았습니다.
- 80% 예측 구간 포함률: 분위수 회귀 원본 **67.6%** → 등각 배율 ×1.5 보정 후 **81.1%**. 단, 보정과 측정에 같은 holdout 을 사용했으므로 낙관적 수치이며, 실데이터에서는 별도 보정 구간(calibration split) 분리가 필요합니다.
- 순열 중요도 상위: 지역 시세지수 ≫ 단지 프리미엄 > 층 > 경과연수 > 지하철 거리 > 전용면적
- 해석상 주의: 샘플 데이터는 생성 규칙이 단순해 R² 가 매우 높게 나옵니다. 실거래 데이터에서는 동·향·조망·리모델링 등 미관측 요인으로 오차가 커질 것으로 예상합니다.

## 2. 맞춤 매물 추천 (`backend/app/services/recommendation.py`, `recommend-weighted-v1`)

1. 조건 수집 → 2. 필터(거래유형·면적·방·준공, 예산 +5% 허용) → 3. 예산·지역 적합도 → 4. 교통·학군·생활 인프라 점수 → 5. 가격 경쟁력(호가 vs AI 적정가 / 최근 1년 전세 실거래 평균, 월세는 전환율 5% 환산) → 6. 목적별 기본 가중치 × 사용자 중요도(1~5) → 7. 가중 평균 점수 → 8. 단지당 최대 2건으로 다양화 후 상위 K

| 구성요소 | 실거주 가중치 | 투자 가중치 |
|---|---|---|
| 예산 / 지역 | 0.20 / 0.15 | 0.15 / 0.10 |
| 교통 / 학군 / 인프라 | 0.15 / 0.10 / 0.12 | 0.08 / 0.04 / 0.04 |
| 가격 경쟁력 | 0.18 | 0.24 |
| 시세 흐름(전년 대비, ±10% 상한) | 0 | 0.12 |
| 거래 활발도 / 가격 안정성 | 0.05 / 0.05 | 0.13 / 0.10 |

- 상승률 단독 순위 방지: 시세 흐름은 투자 목적에서만, 상한을 둔 일부 가중치로 반영하고 변동성(안정성)을 함께 반영
- 주의 사항 자동 생성: 예산 초과, 적정가 대비 고호가, 노후 단지, 높은 전세가율(전세), 높은 변동성(투자), 낮은 거래량, 인프라 데이터 부재, 샘플 데이터

### 2.1 오프라인 평가 (`ai/recommendation/evaluate.py`, 시뮬레이션 사용자 23명, K=10)

| 방법 | Precision@10 | Recall@10 | NDCG@10 |
|---|---|---|---|
| **aptpick 추천** | **0.683** | **0.683** | **0.735** |
| 최저가순 | 0.483 | 0.483 | 0.480 |
| 무작위 | 0.461 | 0.461 | 0.454 |

- 정답 집합: persona 의 숨은 선호(중요도×입지 점수 + 가격 경쟁력 + 노이즈, 예산 초과 패널티) 상위 20% — 실제 사용자 피드백이 아닌 대리 평가입니다. 서비스 운영 후 관심 등록·클릭 로그(`recommendation_history`, `favorite_properties`)로 재평가합니다.

## 3. 가격 이상치 탐지 (`backend/app/services/anomaly.py`, `ai/anomaly_detection/detect.py`)

| 방법 | 탐지 건수 | Precision | Recall |
|---|---|---|---|
| **운영 규칙: robust z(MAD) ≥ 3.5 + 편차 ±15%** | 55 | **0.655** | **0.837** |
| IsolationForest (contamination 1.5%) | 60 | 0.417 | 0.581 |
| (개선 전) robust z 단독 | 278 | 0.130 | 0.837 |

- 라벨: 샘플 데이터에 주입한 ‘직거래 + 22~38% 할인’ 거래 43건
- 평가 결과에 따라 층·향 차이로 인한 정상 편차(약 ±10%) 오탐을 줄이도록 최소 편차 조건(15%)을 추가했습니다.
- 지역 급등·급락: 3개월 이동평균 ㎡당가 전월 대비 ±1.5%
