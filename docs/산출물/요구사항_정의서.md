# 요구사항 정의서

> 작성: 박미금 (PM · Frontend) · 기준일 2026-11-26 · 상태 표기: ✅ 구현 · 🟡 부분 구현/외부 설정 필요 · ⬜ 미구현

## 1. 개요
- 서비스명: aptpick — “데이터로 분석하고, AI로 찾는 나에게 맞는 부동산”
- 대상: 주택 구매자, 전월세 수요자, 투자자(B2C) / 공인중개사·중개법인·부동산 기업(B2B 관리 시스템)
- 원칙: 실거래가(계약 가격)와 매물 호가 구분 표시, 모든 통계·AI 결과에 기준일·출처 표시, 데이터 없는 수치 생성 금지

## 4. 제약 및 가정
- 공공데이터 인증키가 없는 환경에서는 가상 샘플 데이터로 시연하며, 실제 시세로 오인되지 않도록 모든 화면에 표시합니다.
- 생활 인프라 POI 는 현재 샘플 데이터이며, 실데이터 연동(Kakao Local 카테고리 검색 등)은 후속 과제입니다.
- 매물(호가) 데이터는 중개업체 제휴·관리자 등록을 전제로 하며 외부 포털 데이터를 수집하지 않습니다.
