## 2. 수집 파이프라인 (`backend/app/services/collector.py`)
1. 관리자 > 데이터 관제에서 API·지역·계약년월 선택 → 백그라운드 실행
2. 페이지 단위 호출(1,000건), 실패 시 지수 백오프 3회 재시도, `resultCode` 검증(오류 메시지 기록)
3. 스키마 검증: 필수 필드(단지명·면적·계약일·금액) 누락 행은 `invalid` 로 집계·제외
4. 정규화: 금액 콤마 제거·만원 정수, 면적 소수 2자리, 층 정수, 지역코드 5자리, 해제(`cdealType=O`) 표시
5. 중복 제거: 원천 키 해시(`source_key`) — 재수집 시 `duplicates` 로 집계
6. 단지(aptSeq)·평형(면적) 자동 매핑 → 적재 → `data_collection_logs` 기록 → 지역 통계·AI 모델 재계산 → WebSocket `data_updated`
- 원본 CSV 전처리 도구: `ai/data_processing/preprocess.py` (결측률·중복 제거·이상치 플래그 리포트)
- 실거래 데이터(계약 완료)와 매물(호가)은 별도 테이블(`transaction_history`/`rental_history` vs `properties`)에 저장

## 3. 분석 지표 정의 (`backend/app/services/stats.py`)

| 지표 | 정의 |
|---|---|
| 평균 매매가 / 중위가 | 월별 지역 매매 거래금액 평균·중앙값 (해제 거래 제외) |
| ㎡당 평균가 | Σ거래금액 / Σ전용면적 (면적 구성 차이 보정) · 평당가 = ×3.3058 |
| 변동률 | ㎡당가 3개월 이동평균의 전월(MoM)·전분기(QoQ)·전년 동월(YoY) 대비 변화율 |
| 전세가율 | 전세(월세 0) ㎡당 보증금 / 매매 ㎡당가 |
| 변동성 | 최근 12개월 월간 변동률 표준편차 (연환산 ×√12) |
| 거래량-가격 상관 | 월 거래량과 MoM 변동률의 피어슨 상관계수 |
| 평형별 분포 | 최근 12개월 60㎡ 이하 / 60~85 / 85~102 / 102~135 / 135㎡ 초과 구간별 건수·평균가·㎡당가 |
| 공급·수요 지표 | 세대수·단지 수, 등록 매물 / 월평균 거래, 전월세/매매 거래비, 월세 비중, 갱신계약 비중 |
| 급등·급락 | 3개월 이동평균 MoM ±1.5% 이상 |

## 4. 샘플 데이터 분석 결과 (가상)
- 분석 대상 15개 시군구, 51개 단지, 매매 3,966건 · 전월세 약 5,600건 (2023-11 ~ 2026-10)
- 2026-10 기준 ㎡당 평균가(3개월 이동평균) 약 1,281만원, 전년 대비 -0.30%, 평균 거래가 약 12억 774만원, 전세가율 52.0%
- 생성 규칙상 서울 강남·서초·송파 등은 상승 추세, 일산·수성·세종은 하락 추세로 설정되어 있어 지역별 히트맵·상승·하락 순위가 이를 반영합니다.
- 이 수치들은 데모 시연과 파이프라인 검증 목적이며 보고·발표 시 실제 시장 분석으로 인용해서는 안 됩니다.

## 5. 품질 관리
- 관리자 대시보드: 수집 성공률, API 오류 수, 결측률(층·준공연도), 수집 중복률, 중복 의심 매물, 해제 거래, 실데이터/샘플 건수
- 리포트 수치 검증: 생성 본문 숫자를 근거 통계(JSON)에서 유도 가능한지 자동 대조, 미확인 수치 표시

## 6. 후속 과제
- 공공데이터포털 인증키 발급 후 대상 지역·기간 실거래 적재 → 샘플 데이터 삭제 → 통계·모델 재평가
- 한국부동산원 지수와 자체 집계 지수 비교 검증, 생활 인프라 실데이터(Kakao 카테고리 검색·학교 알리미 등) 연동
