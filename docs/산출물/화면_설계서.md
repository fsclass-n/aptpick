# 화면 설계서

> 작성: 박미금 (Frontend · UI/UX) · 구현 기준: `frontend/src` (React 19 · Vite · Tailwind CSS v4)

## 1. 디자인 시스템
| 항목 | 규칙 |
|---|---|
| 그리드 | 12컬럼(`grid-12`, `container-x` max 1280px), Tablet 8컬럼, Mobile 4컬럼 |
| 스페이싱 | 8px 단위 (Tailwind spacing 2=8px) |
| 폰트 | 제목 SUIT Variable, 본문 Pretendard Variable |
| 타이포 | H1 32 · H2 24 · H3 20 · Body 16 · Caption 13 (`h1`·`h2`·`h3`·`caption` 유틸리티) |
| 색상 | Primary 딥 블루 `brand-600 #1f4bc9`, Secondary 네이비 `navy-900 #0b1730`, Accent 민트 `mint-500 #14b8a6`, 상승 `#e11d48`, 하락 `#2563eb`, 보합 `#64748b`, 추천 `#16a34a`, 주의 `#ea580c` |
| 아이콘 | Lucide React 단일 세트 |
| 테마 | 일반 페이지 라이트 고정, 시장 분석·관리자 화면은 토글로 다크(페이지 루트 `.dark`) |
| 컴포넌트 | `ui.jsx`(Card·Badge·Stat·DataMeta·Segmented·Pagination·Modal·ScoreBar·Async), `PropertyCard`, `MapView`, `Charts`, `Markdown` |

## 2. 전역 레이아웃
- `MainLayout`: Header(로고 · GNB 6종 · 알림 · 관리자 · 프로필) / Outlet / Footer / To the Top
- GNB: 홈 · 아파트 찾기(매물 검색 · 지도 · 실거래가) · 부동산 시장 분석(지역 동향 · AI 가격 예측) · AI 맞춤 추천 · 관심 매물 · 부동산 리포트
- 모바일(<1024px): 햄버거 → 우측 슬라이딩 드로어(경로 이동 시 자동 닫힘, 배경 스크롤 잠금)
- 보호 라우트: 비로그인 → `/login?next=<원래 경로>` → 로그인 후 복귀
- Footer: 서비스 소개 · 서비스 안내 · 고객센터/제휴 문의(모달) · 약관 · 개인정보 · 데이터 출처 · GitHub · 프로젝트 안내 · 팀 · © 2026 aptpick

## 3. 화면 목록

| 경로 | 화면 | 주요 구성 |
|---|---|---|
| `/` | 메인 | 히어로 + 통합 검색, 인기 지역, 시장 KPI 4종, 지역 평균가, 최근 실거래, AI 추천 4건, 리포트 3건, 기능 6종 |
| `/search` | 아파트 찾기 | 좌측 필터(모바일 전체 화면), 매물(호가)/실거래가 탭, 정렬, 카드 그리드, 페이지네이션, 검색 조건 저장, 호가·실거래 안내 |
| `/map` | 지도 탐색 | 좌측 단지 목록(데스크톱), 지도(마커·클러스터·인프라 레이어·범례), 선택 단지 카드, 모바일 지도/목록 토글 |
| `/market` | 시장 분석 | KPI 5종, 전체 추이, 지역 지표 표, 연간 상승·하락 막대, 히트맵, 지역 비교, 지역 상세(추이 3종·분기·평형 분포·연도·상위 단지·지표 4종), 급등락·이상 거래 |
| `/predict/:id` | AI 가격 예측 | 지역→단지→평형 선택, 추정가 카드(범위·신뢰도·3개월 전망·기준일·대상 기간·모델 버전), 기간별 실거래, 한계, 층/경과연수 영향, 평형별·유사 단지, 모델 성능·피처 중요도 |
| `/recommend` | AI 맞춤 추천 | 조건 폼(목적·유형·지역 칩·예산·면적·방·준공·중요도 슬라이더·선호 저장), 알고리즘 8단계 안내, 결과 카드(점수·구성요소 9종·추천 이유·주의 사항·유사 거래) |
| `/apartments/:id` | 단지 상세 | 헤더(배지·주요 정보·관심·알림·AI 예측), 평형별 시세 + 그래프, AI 분석 의견, 평형 비교, 실거래/전월세, 이상 거래, 등록 매물, 지도·입지 점수·인프라·주변 단지 |
| `/favorites` | 관심 매물 | 관심 단지·매물(평형별 시세), 가격 알림 목록(ON/OFF·삭제) |
| `/mypage` | 마이페이지 | 탭: 회원 정보·탈퇴 / 선호 조건 / 검색 내역(저장·최근) / 알림 / AI 추천 이력 |
| `/reports`, `/reports/:id` | 리포트 | 유형 필터, 카드(생성기·수치 검증·샘플 배지), 자연어 Q&A, 상세(검증 결과·Markdown 본문) |
| `/login` | 로그인 | 로그인/회원가입 탭, 카카오·네이버·Google, 테스트 사용자·테스트 관리자, 관리자 키 로그인 |
| `/admin/*` | 관리자 | 대시보드 / 회원 / 매물 / 데이터 관제 / AI 모델 / 리포트 / 운영(감사 로그·문의·공지) — 테스트 관리자 읽기 전용 배너 |
| `/about`, `/policy/:kind` | 안내 | 팀·파이프라인·기술 스택·배포 주소 / 약관·개인정보·데이터 출처 |

## 4. 상태·예외 처리
- 로딩: 스켈레톤/스피너, 오류: 재시도 버튼, 빈 결과: 안내 문구
- Render 콜드 스타트 시 연결 실패 메시지 안내, 401 시 자동 로그아웃
- 테스트 관리자: 쓰기 버튼 `disabled` + “테스트 관리자 계정은 읽기 전용입니다.” (백엔드 403 이 최종 방어선)
